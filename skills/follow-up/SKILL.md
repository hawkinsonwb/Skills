# Follow Up

1. Recover the active task, last completed step, and pending decision or blocker from the conversation, workspace guidance, tickets, and local work.
2. Refresh relevant external state with available tracker/PR/CI tools. Continue the next authorized action from preserved work; elapsed time does not clear a blocker or supply approval.
3. For review comments or PR responses, read [review feedback](references/review-feedback.md).
4. Report what changed and what remains. If still blocked, identify the needed action. If the intended task is ambiguous, ask a focused question.

Preserve the existing scope and user checkpoints. A request to follow up does not by itself authorize posting, approval, or merging.
